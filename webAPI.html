JSON Rules

JSON (JavaScript Object Notation) rules dictate how you structure and format lightweight data

Rule 1: Objects

All object must be enclosed in curly braces { } and use a comma to separate key/value pairs

Code sample: { "key": "value", "key2": "value2"}

Rule 2: Keys

All keys must be strings and enclosed in double quotes

Code sample: { "fname": "Josh" }

Rule 3: Values

All values must be strings, numbers, booleans, null, arrays, or objects. Functions and undefined are not allowed.

Code sample: { "fname": "Josh", "age": 20, "isStudent": true }

Rule 4: Arrays

All arrays must be enclosed in square brackets [ ] and use a comma to separate elements

Code sample: [ "item1", "item2", "item3" ]

Rule 5: Comments

Comments are not allowed in JSON. Use a string value instead.

Code sample: { "fname": "Josh", "comment": "No comments allowed" }

Rule 6: Trailing Commas

Trailing commas are not allowed in JSON objects or arrays.

Code sample: { "fname": "Josh", "age": 20, "isStudent": true, }
